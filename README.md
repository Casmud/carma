# carma
An open source car management app

## Installation

Use [UV](https://docs.astral.sh/uv/) to install carma.

```bash
uv sync
```

## Usage

Carma is build using [Reflex](https://reflex.dev/). You can run the app locally by running the following commands:

```bash
reflex db init #only required first time to initialize the database
reflex run
```
